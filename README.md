# AllTechs downloads

Official installers for apps by **Chief Alltechs Ventures** ([chiefalltechs.com](https://chiefalltechs.com)).
Everything here is free. This repository holds downloads only, not source code.

The easiest way to get an app is the apps page: **https://apps.chiefalltechs.com**

## AllTechs Support (remote desktop help)

| Platform | Download |
|---|---|
| Windows installer | [AllTechs-Support-Setup.exe](https://github.com/chiefbryn/alltechs-downloads/releases/latest/download/AllTechs-Support-Setup.exe) |
| Windows portable (no install) | [AllTechs-Support-Portable.exe](https://github.com/chiefbryn/alltechs-downloads/releases/latest/download/AllTechs-Support-Portable.exe) |
| Mac, Apple Silicon (M1 and later), macOS 13 Ventura or newer | [AllTechs-Support-mac-arm64.dmg](https://github.com/chiefbryn/alltechs-downloads/releases/latest/download/AllTechs-Support-mac-arm64.dmg) |
| Mac, Intel, macOS 13 Ventura or newer | [AllTechs-Support-mac-x64.dmg](https://github.com/chiefbryn/alltechs-downloads/releases/latest/download/AllTechs-Support-mac-x64.dmg) |
| Older Mac, Apple Silicon, macOS 11 Big Sur or 12 Monterey | [AllTechs-Support-mac-legacy-arm64.dmg](https://github.com/chiefbryn/alltechs-downloads/releases/latest/download/AllTechs-Support-mac-legacy-arm64.dmg) |
| Older Mac, Intel, macOS 10.15 Catalina to 12 Monterey | [AllTechs-Support-mac-legacy-x64.dmg](https://github.com/chiefbryn/alltechs-downloads/releases/latest/download/AllTechs-Support-mac-legacy-x64.dmg) |

- **Windows:** the files are not code-signed, so SmartScreen may say "unknown publisher". Click **More info → Run anyway**. The app asks for Administrator so it can help with admin tasks.
- **Mac:** the app is not notarized by Apple. After the first launch is blocked, go to **System Settings → Privacy & Security → Open Anyway** (on macOS 10.15 to 12: **System Preferences → Security & Privacy → Open Anyway**).
- **Which Mac file?** Apple menu → **About This Mac**. macOS 13 or newer: use the standard file. macOS 10.15, 11 or 12: use the "legacy" file. "Chip: Apple M…" means Apple Silicon; "Processor: Intel" means Intel.
- **No install needed to receive help from a Chromebook or any computer browser:** open https://support.chiefalltechs.com and choose **Share My Screen** (view-only; the supporter can see but not control).
- To check a download, compare its SHA-256 with `SHA256SUMS.txt` in the same release.
